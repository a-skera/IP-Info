# IP Address Information Tool

A lightweight Python networking utility that
analyzes IPv4 and IPv6 addresses.

## Features

- IP address validation
- IPv4 and IPv6 identification
- Private and public classification
- Loopback detection
- Multicast and reserved address detection
- Reverse DNS lookup

## Requirements

- Python 3.8+
- No external dependencies

## Usage

python ip_info.py 8.8.8.8

## Technologies

- Python
- ipaddress
- socket
- argparse
